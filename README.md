# Pineapple School

A responsive school website built with Next.js App Router, React, TypeScript and Tailwind CSS 4.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production

```bash
npm run build
npm start
```

Frontend-only implementation. Existing page sections, school information, imagery references and demo interactions are retained while the Grange branding is updated to Pineapple School.
